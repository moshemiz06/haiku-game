# Orbit Flip

Orbit the sun, reverse your direction, and dive for heat. Dodge asteroids whose paths the sun's gravity bends, grab stardust, skim for near-miss bonuses, and catch the rare gold comet.

**Play:** https://moshemiz06.github.io/haiku-game/

## Controls

| Action | Keyboard | Mouse / touch |
| --- | --- | --- |
| Reverse orbit | Space | Click / tap |
| Dive toward the sun (release to climb back out) | Hold Space | Hold click / tap |
| Pause | P or Esc | Pausing also happens when the window loses focus |
| Mute | M | |

## Running locally

It's a single file with no dependencies. Open `index.html` in a browser.

Created in [T3 Code](https://t3.codes).
